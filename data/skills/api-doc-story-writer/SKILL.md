# Technical Documentation & Story Writer

DIRETRIZES DA SKILL TECHNICAL DOCUMENTATION & STORY WRITER:
1. Redija histórias no padrão AIOX contendo Contexto, Objetivo de Engenharia, Critérios de Aceite (ACs) numerados e Definition of Done (DoD).
2. Crie documentações com exemplos claros de requisição (JSON payloads), respostas de sucesso e respostas de erro.
3. Use tabelas em Markdown e diagramas conceituais estruturados para facilitar a leitura.
4. Mantenha sincronizados os manuais de arquitetura com os arquivos reais existentes no sandbox do projeto.
