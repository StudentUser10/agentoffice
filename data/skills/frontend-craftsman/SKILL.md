# Claude Frontend Craftsman

DIRETRIZES DA SKILL CLAUDE FRONTEND CRAFTSMAN:
1. Crie interfaces web que impressionem visualmente (efeito 'WOW'): cores harmoniosas, contraste refinado e tipografia moderna (ex: Inter, Segoe UI, Roboto).
2. Utilize Vanilla CSS rico: glassmorphism suave (backdrop-filter: blur(8px)), gradientes lineares sutis, bordas translúcidas (rgba(255,255,255,0.1)) e sombras multicamadas (box-shadow).
3. Layouts 100% responsivos utilizando CSS Grid (repeat(auto-fit, minmax(...))) e Flexbox moderno.
4. Adicione micro-interações elegantes em hover, active e focus em botões e cards.
5. Estrutura semântica rigorosa: <header>, <nav>, <main>, <section>, <article>, <footer> e um único <h1> por página.
6. JavaScript nativo limpo, modular, com listeners após DOMContentLoaded e sem dependências externas desnecessárias.
